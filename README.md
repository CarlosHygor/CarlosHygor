## Projetos em Destaque

### Projeto GLC - Sistema de Gestão Hierárquica e Mapeamento Demográfico
Plataforma web focada em geoprocessamento e gestão de equipes e colaboradores.
* **Arquitetura e Segurança:** Construção de API REST com forte aplicação de princípios SOLID e autenticação via tokens JWT, garantindo o isolamento hierárquico das informações.
* **Alta Performance e Otimização:** Resolução de gargalos de processamento com a implementação de Caffeine Cache, cache de navegador e compressão GZip, reduzindo o tamanho dos *payloads* em cerca de 75% (de ~350KB para ~80KB).
* **Geoprocessamento em Larga Escala:** Processamento eficiente de dados espaciais via GeoJSON (mais de 62 mil linhas) para a renderização fluida de mapas do estado do Acre e seus municípios.

### SCRP - Sistema de Controle de Relatórios e Projetos (Web Academy / Motorola)
Sistema web desenvolvido para automação de processos fiscais de P&D (SUFRAMA).
* **Arquitetura Multi-tenancy:** Implementação de "Tokens de Contexto" para isolamento seguro de dados entre múltiplos projetos.
* **Integração Assíncrona:** Automação da gestão de pastas e envio de arquivos utilizando a API do Google Drive.
* **Liderança e DevOps:** Atuação como SCRUM Master validando entregas diretamente com Product Owners. Estruturação da esteira de CI/CD utilizando Docker e GitHub Actions.
